HyperV GPU-PV 显卡虚拟化工具 — 使用说明
==========================================

一、运行环境
  1. Windows 10 / 11（家庭版 / 专业版 / 企业版均可）
  2. 需要管理员权限（程序会自动请求提权，UAC 弹窗点「是」）
  3. 需要 .NET 8 Desktop Runtime：双击「启动程序.bat」会自动检测，
     缺失时会自动打开微软官网下载页，安装后再双击即可
  4. 显卡：需要支持 GPU 分区（GPU-PV）的显卡；Intel 核显与 AMD 显卡
     兼容性最好，NVIDIA 消费级显卡可能需要特定驱动版本（以实测为准）

二、快速使用
  1. 双击「启动程序.bat」
  2. 软件自动检测 Hyper-V 状态 / 虚拟机列表 / 可分区显卡
  3. 若提示未开启 Hyper-V：点击「一键开启 Hyper-V」，完成后重启电脑
  4. 在「虚拟机列表」选中目标虚拟机，在「可分区显卡」选中显卡，
     拖动滑块设置分配比例（建议 50%）
  5. 点击「部署 GPU 虚拟化」，等待日志执行完成
     （全过程自动：关虚拟机 → 配置分区 → 设置 MMIO → 开机 → 同步显卡驱动 → 重启）
  6. 进入虚拟机，在「设备管理器 → 显示适配器」中确认显卡已出现

三、卸载 / 还原
  选中虚拟机 → 点击「卸载 GPU 虚拟化」，
  即可移除分区、复位 MMIO，并按原状态恢复虚拟机。

四、常见问题
  - 检测不到 Hyper-V：先点击「一键开启 Hyper-V」再重启电脑；
    家庭版会自动走兼容方式安装组件包
  - 显卡显示「不可分配」：先更新显卡驱动并重启，再刷新重试
  - 部署成功但虚拟机里看不到显卡：驱动自动同步要求虚拟机内存在与
    宿主机同名的管理员账户；也可手动把宿主机显卡驱动目录拷贝到虚拟机
    C:\Windows\System32\HostDriverStore\FileRepository 后重启虚拟机
  - 部署中途失败：脚本会自动回滚并保持虚拟机安全状态，可排查后重试
  - 部署 / 卸载过程会开关虚拟机，请先保存虚拟机内正在进行的工作

五、安全提示
  操作会修改虚拟机配置（关机 / 开机 / MMIO / 分区适配器），
  建议先为重要虚拟机创建检查点（快照）并备份数据。
