# Hyper-V 显卡虚拟化部署工具（C# WPF）实现计划

## Context

用户需要一款 Windows 桌面软件，自动化"Hyper-V GPU 分区（GPU-PV）"部署流程（源自 [rainng.com 教程](https://www.rainng.com/hyperv-vgpu/)）：
自动列出宿主机 Hyper-V 虚拟机 → 自动检测可分区 GPU → 选中虚拟机自动填名称 → 选 GPU 与分配比例 → 一键部署（关 VM→配分区→拷驱动→重启）→ 支持卸载回滚。

可行性已验证：所有关键步骤均为可调用的 PowerShell Cmdlet；开源项目 Easy-GPU-PV 存在但是纯脚本无 GUI。用户已确认用 **C# WPF** 开发。

## 环境准备（必须先做）

- 本机有 .NET 8 运行时（8.0.31）但**无 .NET SDK**，无 Visual Studio，无 winget。
- 用官方 dotnet-install.ps1 把 **.NET 8 SDK 安装到用户目录** `%USERPROFILE%\.dotnet`（无需管理员权限）。安装后构建命令需使用该目录的 dotnet.exe。

## 技术决策

- 目标框架 `net8.0-windows` + WPF；**不引入任何 NuGet 包**（System.Text.Json 为 BCL 内置）。
- 不用 MVVM 框架/DI，WPF Code-behind 直写，保持简单。
- 所有 Hyper-V 操作：以管理员权限启动子进程 `powershell.exe`（Windows PowerShell 5.1，自带 Hyper-V 模块）执行内嵌 `.ps1` 脚本。不用 System.Management.Automation SDK（运行时加载 Hyper-V 模块有坑）。
- 脚本统一输出约定：普通行走 stdout 转发为日志；最后一行 `#JSON#{"ok":bool,"message":"...","data":{...}}` 供 C# 解析。
- exe 用 `app.manifest` 声明 `requireAdministrator`；启动时再校验一次管理员身份。
- `.ps1` 以 Content 随 exe 发布到 `Scripts` 目录。

## 核心服务

- **PowerShellRunner.Run(scriptFile, args, logLine)**：启动 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File ...`，重定向 stdout/stderr 逐行转发日志，识别 `#JSON#` 行返回 PsResult；处理超时（部署 10 分钟）与退出码兜底。
- **HyperVService.GetEnvironmentInfo(log)**：调 `info.ps1` 一次进程返回 `data.vms[]`、`data.gpus[]`。厂商匹配：InstanceId 正则 `VEN_XXXX` → 10DE=NVIDIA / 1002=AMD / 8086=Intel / 其他=未知。无 Hyper-V 时 `ok:false`，UI 优雅提示并禁用操作按钮。
- **DeployService.Deploy(vm, gpu, share, vmUser, vmPassword, log)** / **Uninstall(vmName, log)**：拼参数调对应脚本，转发日志、解析结果。

## 部署状态机（deploy.ps1，脚本内顺序执行 + 内联回滚）

| 步骤 | 操作 |
|---|---|
| S0 | 预校验：VM 存在、GPU 可分区、Share∈(0,1] |
| S1 | Stop-VM（若 Running/Saved），等待 Off |
| S2 | Remove-VMGpuPartitionAdapter（清理旧配置，幂等） |
| S3 | Add-VMGpuPartitionAdapter -InstancePath <GPU InstanceId> |
| S4 | Set-VMGpuPartitionAdapter 按 Share 缩放 Min/Optimal/Max × VRAM/Compute/Decode/Encode（值对齐 1MB） |
| S5 | Set-VM -GuestControlledCacheTypes $true -LowMemoryMappedIoSpace 1GB -HighMemoryMappedIoSpace 32GB（按教程默认值） |
| S6 | 解析宿主驱动目录（Get-PnpDevice→Win32_PnPSignedDriver→dism /online /get-drivers 正则）→ PowerShell Direct（New-PSSession -VMName + 凭据，Copy-Item -ToSession）拷入 VM `C:\Windows\System32\HostDriverStore\FileRepository`；凭据为空则跳过并提示手动 |
| S7 | Start-VM |

**回滚**：S3~S6 任一步失败 → 内联回滚（Remove-VMGpuPartitionAdapter + Set-VM -GuestControlledCacheTypes $false）→ 输出 `ok:false` + 失败步骤与原因，VM 保持关机。S7 失败不回滚，提示"分区已配好，请手动启动 VM"。脚本内统一 `try/catch` 输出 `#JSON#` 结束行。

**uninstall.ps1**：Stop-VM（按原状态）→ Remove-VMGpuPartitionAdapter → Set-VM -GuestControlledCacheTypes $false（MMIO 复位）→ 按原状态 Start-VM。

## 实现步骤（顺序）

1. **环境**：下载执行 dotnet-install.ps1 装 .NET 8 SDK 到 `%USERPROFILE%\.dotnet`，验证 `dotnet --version`。
2. **项目骨架**：sln + csproj + app.manifest + App/MainWindow 占位 + Scripts 目录 + csproj 的 Scripts Content 项；`dotnet build` 验证编译通过。
3. **PowerShellRunner + Models**：进程封装与 `#JSON#` 解析（用临时测试脚本验证链路）。
4. **info.ps1 + HyperVService + 刷新列表**：VM DataGrid 与 GPU 下拉出数据；无 Hyper-V 时优雅提示。
5. **UI 完整布局**：分区、滑块+百分比、凭据框、按钮禁用逻辑、日志区。
6. **deploy.ps1 + DeployService**：先跑通 S0~S5，再全链路 S6+S7。
7. **uninstall.ps1 + 卸载按钮**。
8. **打磨**：错误注入验证回滚（错 GPU ID / 错密码 / Share=0）、按钮状态、文案。

## 验证

- **编译**：`dotnet publish -c Release -r win-x64` 产出 exe；双击验证 UAC 提权；Scripts 目录随发布输出。
- **本机无 Hyper-V 情况**：启动 → 刷新列表显示"未检测到 Hyper-V 环境"，按钮禁用，不崩溃。
- **真机（有 Hyper-V + 可分区 GPU）**：刷新出 VM/GPU → 部署全链路日志逐步通过 → VM 内设备管理器/`Get-VMGpuPartitionAdapter` 确认 12 个参数按 Share 缩放 → 卸载后分区移除、MMIO 复位、VM 还原。
